# Plataforma de Vídeos IA UGC
Plataforma para criação automática de avatares e edição de conteúdo em vídeo com inteligência artificial, baseada no projeto OpenShorts.

## Ferramentas disponíveis na plataforma
### Imagens- Gerar imagens: gera imagens atraentes a partir de texto- Editar com IA: edita e modifica imagens existentes com inteligência artificial- Melhorar qualidade de imagem: aumenta resolução e nitidez das imagens- Remover plano de fundo: isola os elementos do fundo da imagem- Melhorar pele: refina textura e detalhes de pele em retratos
### Vídeos- Gerar vídeo: cria vídeos a partir de prompts de texto simples- Modificar vídeo: transforma vídeos já existentes usando um prompt- Editor de vídeos: edita e aprimora projetos de vídeo- OpenShorts CLI: converte vídeos longos para formato vertical 9:16 otimizado para redes sociais
### Áudio, voz e música- Texto para voz: gera narrações de voz realistas- Gerar efeitos sonoros: cria efeitos sonoros com IA- Clonagem de voz: clona ou cria vozes personalizadas- Modificar voz: converte uma voz em outro timbre- Gerar música: compõe faixas musicais a partir de texto
- Geração de avatares virtuais
- Edição automática de vídeos curtos
- Suporte a legendas e narração automática
- Ferramentas para conteúdo UGC

## Como usar
1. Clone ou baixe o repositório
2. Instale as dependências do projeto
3. Execute o arquivo principal para iniciar a plataforma
